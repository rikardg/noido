# Zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zoom (keys, Mod+wheel, pinch), fit width / fit page, and a scroll position held in document terms across zoom and resize.

**Architecture:** `noido-core` gains a `View` (zoom mode, scale, viewport, offset) built on a `Layout` that arranges pages for a given scale. The egui frontend syncs egui's scroll offset into `View` each frame, feeds it input, and applies the offset it returns.

**Tech Stack:** as before.

**Spec:** `docs/superpowers/specs/2026-10-25-zoom-design.md`

## Global Constraints

- `noido-core` stays free of egui.
- `MIN_ZOOM = 0.1`, `MAX_ZOOM = 4.0`, `ZOOM_STEP = 1.25`; `MARGIN`, `PAGE_GAP`, `SCREEN_OVERLAP` unchanged.
- Start mode: fit width. No `Mod`+`0` binding.
- fmt, clippy `-D warnings`, `cargo test --workspace` pass after every task.

## Review Focus

1. **Zero pages / empty viewport (first frame)**: no panic, no NaN; offset stays (0, 0). → `View` tests `zero_pages_is_safe`, `first_viewport_keeps_top`.
2. **Zoom near the end of the document**: offset clamps to the new content size, never past the end. → `zoom_out_at_bottom_clamps`.
3. **Anchor in a gap or margin between pages**: zooming there must not jump to a page edge. → `anchor_in_gap_is_stable`.
4. **Mod+wheel with the pointer outside the page view**: anchors at the window centre instead. → frontend passes `None`; `View::zoom_by(factor, None)` test `zoom_by_without_anchor_uses_centre`.
5. **Fit modes at extreme window sizes**: scale stays inside 0.1–4.0. → `fit_scales_are_clamped`.

### Task 1: Layout arranges for a given scale; document points

**Interfaces — Produces:**
- `Layout::new(page_sizes: Vec<Size>) -> Self` (unchanged signature).

### Task 3: Frontend on View

**Files:** Modify `crates/frontends/gui-egui/src/app.rs`, `main.rs`.

- `NoidoApp` holds `view: View` instead of `layout`/`viewport`; keeps `last_offset: Option<Vec2>` and `last_inner: Option<Rect>` from the previous frame's `ScrollAreaOutput` (`state.offset`, `inner_rect`).
- Per frame, in order: receive renders; `view.set_viewport_size(inner size)`; `view.scrolled_to(offset)`; unless `text_edit_focused()`: map `Event::Key { pressed: true, key, modifiers }` to `KeyPress { key, command: modifiers.command }` → `view.apply`; if `input.zoom_delta() != 1.0` → `view.zoom_by(delta, pointer inside inner rect ? Some(pointer − inner.min) : None)`.
- `ScrollArea::both().auto_shrink(false)`; call `.scroll_offset(vec2(x, y))` only when `view.offset()` differs from the synced offset by more than 0.5 on either axis.
- Inside `show_viewport`: allocate `vec2(content_width, content_height)`, draw pages via `view.layout().page_rect`; render scale `render_scale(size, view.scale() * ppp, MAX_RENDER_SIDE)`; skip requests when scale ≤ 0.
- `main.rs`: before running, `ctx.options_mut(|o| o.zoom_with_keyboard = false)`.
- Map egui keys: `PageUp, PageDown, Plus, Equals, Minus, W, F`.
