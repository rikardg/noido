# PageUp / PageDown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PageDown / PageUp scroll the viewer by one screenful, through a keymap in `noido-core`.

**Architecture:** `noido-core` gains `Key`, `Action`, `Keymap` (data) and `scroll_target` (pure function). `gui-egui` maps egui key events to `Key`, looks up the action and sets the scroll area's offset.

**Tech Stack:** as slice 1.

**Spec:** `docs/superpowers/specs/2026-10-25-page-keys-design.md`

## Global Constraints

- `noido-core` stays free of egui.
- `SCREEN_OVERLAP = 0.1` (fraction of the visible height kept on screen).
- fmt, clippy `-D warnings`, `cargo test --workspace` pass.

## Review Focus

1. Document shorter than the window: PageDown must not scroll (offset stays 0). → `scroll_target` test.
2. Near the end: PageDown lands exactly at the bottom, not past it. → `scroll_target` test.
3. Held key: each repeat event scrolls once. → frontend counts every pressed `Key` event, including repeats.

### Task 1: Keymap and scroll actions in core

**Files:** Create `crates/noido-core/src/keymap.rs`; modify `crates/noido-core/src/lib.rs`.

**Interfaces — Produces:**
- `#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)] pub enum Key { PageUp, PageDown }`
- `#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Action { ScrollScreenUp, ScrollScreenDown }`
- `pub struct Keymap` with `pub fn native() -> Self` and `pub fn action(&self, key: Key) -> Option<Action>`
- `pub const SCREEN_OVERLAP: f32 = 0.1;`
- `pub fn scroll_target(action: Action, offset: f32, viewport_height: f32, content_height: f32) -> f32`: moves by `viewport_height * (1 - SCREEN_OVERLAP)`, clamped to `0..=max(0, content_height - viewport_height)`.

### Task 2: Frontend wiring

- `NoidoApp` gains `keymap: Keymap` and `viewport: Rect` (last frame's scroll viewport, content coordinates).
- Each frame, unless `ctx.text_edit_focused()`: for every `egui::Event::Key { key, pressed: true, .. }` whose key maps to a core `Key` (fn `core_key(egui::Key) -> Option<Key>`) and to an action, fold `scroll_target` over the offset starting from `viewport.min.y`, with `viewport.height()` and `layout.content_height()`. If the offset changed, pass it via `ScrollArea::vertical_scroll_offset`.
- Store the viewport from `show_viewport` into `self.viewport`.
