# Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A settings page choosing the zoom, continuous, dual and odd-left a
never-seen document opens with, stored in a new `noido-settings` crate.

**Architecture:** `noido-core` gets `Defaults` and builds a `View` from them;
`noido-settings` reads and writes `settings.toml` in the config directory;
`gui-egui` applies the defaults before any saved state is restored and shows
the page as an `egui::Modal`.

**Tech Stack:** Rust 2024, egui/eframe 0.37, `directories`, `serde`, `toml`.

**Spec:** `docs/superpowers/specs/2026-10-26-settings-design.md`

## Global Constraints

- No new third-party crates; `noido-settings` uses the workspace's `directories`, `serde`, `toml`, `tempfile` (dev).
- Built-in defaults: zoom fit width, fixed percentage 100, continuous on, dual off, odd pages left on.
- Fixed percentage range 10–400 (`MIN_ZOOM`/`MAX_ZOOM` × 100); 100 % is scale 1.0, the title bar's number.
- Settings apply only to documents with no saved state; the open document never changes.
- File: `ProjectDirs::config_dir()/settings.toml`, versioned, `[new_documents]` with `zoom` = `"fit-width"` | `"fit-page"` | `"fixed"`, `zoom_percent`, `continuous`, `dual`, `odd_left`; written atomically.
- Row copy: `Zoom (default: fit width)`, `Continuous (default: on)`, `Dual page (default: off)`, `Odd pages left (default: on)`, radio labels `Fit width`, `Fit page`, `Fixed`, button `Set from current view`, menu label `Settings…`.
- Shortcut: command+`,` (Ctrl+, / ⌘,).
- `cargo clippy --workspace --all-targets -- -D warnings` clean, `cargo fmt`, TDD throughout, commits with `jj commit -m "Area: …"`.

## Review Focus

- Settings that say "not continuous": a new document must open paged on spread 0, at the top, not scrolled to some middle point.
- A fixed zoom with dual on: the first viewport must keep the fixed scale (no refit when the window first gets its size).
- A saved document with the settings set to something else: the saved state wins entirely (each field), including when the saved zoom is fit width and the setting is fixed.
- A hand-edited `settings.toml` with `zoom_percent = 0`, `-5` or `9999`, or an unknown `zoom` string: clamps or falls back field by field, never panics.
- Keys and the wheel while the page is open: D, W, Ctrl+Q's siblings and the wheel do not reach the view; Esc closes only the page (it must not also clear search or close the sidebar).
