# History Implementation Plan

> **Superseded in part:** a history entry is a `DocPoint`, not a
> `ViewState`. See
> [2026-10-31-history-point-only-design.md](../specs/2026-10-31-history-point-only-design.md).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Back and forward between jumps (links, thumbnails, the first hit of a search), on Alt+←/→, the mouse's back/forward buttons and the menu, kept between runs.

**Architecture:** A pure `History` in `noido-core` holds two stacks of `ViewState`s. The app calls `History::leave` before each jump and `back`/`forward` on the new actions, restoring with `View::restore`. `noido-state` saves both stacks in the document's TOML entry.

**Tech Stack:** Rust 2024, egui/eframe 0.37, serde + toml.

**Spec:** `docs/superpowers/specs/2026-10-27-history-design.md`

## Global Constraints

- At most 100 entries going back (`HISTORY_LIMIT = 100`); the oldest go first.
- An entry is a `ViewState` (zoom, scale, continuous, dual, odd_left, centre).
- Keys: Alt+← Back, Alt+→ Forward. Mouse: `PointerButton::Extra1` Back, `Extra2` Forward.
- Menu labels: "Back", "Forward".
- `acts_while_editing` is unchanged: Alt+arrows go to the search field while it has focus.
- Old state files (no history) must still load with their view and sidebar.
- TDD: the failing test first, watched failing. `cargo clippy --workspace --all-targets -- -D warnings` clean, `cargo fmt`.
- Commit with `jj commit -m "<Area>: <what changed>" <paths>`; don't move `main`.

## Review Focus

- **Back with nothing to go back to** (a fresh document, or after going all the way back): nothing moves, nothing panics. Test in Task 1.
- **The same place left twice** (clicking the thumbnail of the page you're on, twice): one entry, not two, so Back isn't a no-op. Test in Task 1.
- **A state file from before this change**: loads with its view and sidebar, empty history. Test in Task 3.
- **Back after the file got shorter** (reloaded with fewer pages than the entry's page): lands on the last page, no panic. Test in Task 4.
- **Back while the settings or info page is open**: nothing moves behind the modal (`handle_input` returns early; keep the mouse buttons inside it). Test in Task 4.

### Task 1: `History` in core

**Files:**
- Create: `crates/noido-core/src/history.rs` (tests in the same file, like the other modules)
- Modify: `crates/noido-core/src/lib.rs` (`mod history; pub use history::*;`)

**Interfaces:**
- Produces:
  - `pub const HISTORY_LIMIT: usize = 100;`
  - `#[derive(Clone, Debug, Default, PartialEq)] pub struct History` with private `back: Vec<ViewState>` (oldest first) and `forward: Vec<ViewState>` (nearest last).
  - `pub fn leave(&mut self, here: ViewState)`: pushes `here` on back unless it equals back's last entry; clears forward; drops the oldest beyond `HISTORY_LIMIT`.
  - `pub fn back(&mut self, here: ViewState) -> Option<ViewState>`: pops back; on success pushes `here` on forward.
  - `pub fn forward(&mut self, here: ViewState) -> Option<ViewState>`: pops forward; on success pushes `here` on back.
  - `pub fn from_parts(back: Vec<ViewState>, forward: Vec<ViewState>) -> Self`: keeps the newest `HISTORY_LIMIT` of back (and of forward).
  - `pub fn back_entries(&self) -> &[ViewState]`, `pub fn forward_entries(&self) -> &[ViewState]`.

- [ ] **Step 1: Write the failing tests** in `history.rs`, with a helper `fn at(page: usize) -> ViewState` (FitWidth, scale 1, continuous, not dual, odd_left true, centre `(page, 0, 0)`):

```rust
#[test] fn back_returns_where_you_left() {
    let mut h = History::default();
    h.leave(at(3));
    assert_eq!(h.back(at(40)), Some(at(3)));
}
#[test] fn forward_returns_where_you_read_on_to() {
    let mut h = History::default();
    h.leave(at(3));
    h.back(at(45));
    assert_eq!(h.forward(at(3)), Some(at(45)));
}
#[test] fn empty_back_and_forward_do_nothing() {
    let mut h = History::default();
    assert_eq!(h.back(at(1)), None);
    assert_eq!(h.forward(at(1)), None);
    assert_eq!(h, History::default());
}
#[test] fn a_jump_after_back_drops_forward() {
    let mut h = History::default();
    h.leave(at(3));
    h.back(at(40));
    h.leave(at(3));
    assert_eq!(h.forward(at(8)), None);
}
#[test] fn the_same_place_left_twice_is_one_entry() {
    let mut h = History::default();
    h.leave(at(3));
    h.leave(at(3));
    assert_eq!(h.back_entries(), &[at(3)]);
}
#[test] fn at_most_the_limit_going_back() {
    let mut h = History::default();
    for page in 0..HISTORY_LIMIT + 5 { h.leave(at(page)); }
    assert_eq!(h.back_entries().len(), HISTORY_LIMIT);
    assert_eq!(h.back_entries()[0], at(5));
}
#[test] fn from_parts_keeps_the_newest() {
    let back = (0..HISTORY_LIMIT + 2).map(at).collect();
    let h = History::from_parts(back, vec![at(1)]);
    assert_eq!(h.back_entries()[0], at(2));
    assert_eq!(h.forward_entries(), &[at(1)]);
}
```

**Interfaces:**
- Consumes: `History` (Task 1), `Action::Back/Forward` (Task 2), `DocState::history` (Task 3).
- Produces (private to `NoidoApp`):
  - field `history: History`, restored in `with_persistence` from `state.history`, written in `doc_state()`.
  - `fn leave_here(&mut self)`: `if let Some(here) = self.view.state() { self.history.leave(here) }`. Called first thing in `follow`'s `Internal` arm, before `go_to_page` on a thumbnail click, and in `go_to_hit` only when `!self.search_state.at_hit` (read it before `go_to_hit` sets it).

  - In `apply`: `Action::Back => self.go_back()`, `Action::Forward => self.go_forward()`.
  - In `handle_input` (after the modal early return): `Event::PointerButton { button: Extra1, pressed: true, .. }` → `apply(Back)`; `Extra2` → `apply(Forward)`. Releases do nothing.
